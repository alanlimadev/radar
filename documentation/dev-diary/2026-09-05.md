## Contexto

Este registro documenta as implementacoes realizadas no backend do sistema de quiz interativo desenvolvido como TCC. O sistema e baseado em uma arquitetura de motor de jogo generico (chamado Radar), que permite que diferentes tipos de jogos sejam plugados modularmente ao servidor WebSocket.

---

## 1. Pontuacao Progressiva por Velocidade de Resposta

### Problema
O sistema de pontuacao anterior atribuia pontos fixos por acerto, gerando empates frequentes entre jogadores que respondiam corretamente na mesma questao.

### Solucao Implementada
**Arquivo:** src/quiz/quiz-game.definition.ts

Implementado um sistema de pontuacao decrescente baseado na **ordem de resposta**:
- O 1o jogador correto recebe **1000 pontos**.
- Cada resposta correta subsequente recebe **50 pontos a menos** que a anterior.
- Pontuacao minima para respostas corretas: **500 pontos**.
- Respostas incorretas recebem **0 pontos**.

**Impacto:** Elimina empates e incentiva respostas rapidas, tornando o jogo mais dinamico e competitivo.

---

## 2. Transicao Direta para GAME_OVER na Ultima Questao

### Problema
Apos a ultima questao do quiz, o jogo transitava para a tela intermediaria de leaderboard por questao (QUESTION_LEADERBOARD), exigindo que o professor clicasse manualmente em Proxima Questao para ir ao podio final.

### Solucao Implementada
**Arquivo:** src/quiz/quiz-game.definition.ts

**Acao SUBMIT_ANSWER:** Quando todos os jogadores ativos responderam e e a ultima questao:
- O estado transiciona diretamente para state.status = GAME_OVER.
- Emite os eventos scoresUpdate, questionEnded e quizEnded em sequencia.

**Acao NEXT_QUESTION:** Quando o host encerra manualmente uma questao ativa que e a ultima:
- Tambem transiciona diretamente para GAME_OVER emitindo os mesmos eventos.

**No gateway (radar.gateway.ts):** O room.status === FINISHED aciona automaticamente quizEnded via isFinished() no room-manager.service.ts.

**Arquivo:** src/quiz/quiz-game.definition.spec.ts

Adicionados 2 novos casos de teste:

1. should transition directly to GAME_OVER and emit quizEnded when all players answer the last question

2. should transition directly to GAME_OVER when host skips/ends the last question while active
   - Valida que quando o host encerra manualmente a ultima questao ainda ativa, tambem vai direto para GAME_OVER.

## 4. Infraestrutura - Compatibilidade Legada no Gateway

**Arquivo:** src/core/gateways/radar.gateway.ts

Adicionados handlers legados que mapeiam eventos do protocolo antigo para o novo motor:
- joinAsHost -> handleRadarJoinAsHost
- joinSession -> handleRadarJoinRoom
- startQuiz -> radar:dispatchAction (START_GAME)
- submitAnswer -> radar:dispatchAction (SUBMIT_ANSWER)
- nextQuestion -> radar:dispatchAction (NEXT_QUESTION)
- getScores -> retorna placar atual
- finishQuiz -> finishRoom + notifyRoomFinished

Adicionada funcao notifyRoomFinished() que transmite radar:roomFinished, sessionFinished e quizEnded a todos os participantes da sala.
